# Twins & Martin Group: social post images

Images for Twins & Martin Group's Instagram and LinkedIn posts, scheduled through Buffer.
Buffer downloads each image from its public link, for example:

https://raw.githubusercontent.com/alejandrolevinton/twinsandmartin-social/main/posts/day-01-new-website.png

- `posts/day-NN-<product>.png`: one 1080x1350 image per post (Day NN of the posting plan).
- The designs live on the "Twins & Martin Social Posts" canvas in Claude; images are rendered
  with `social-tools/render_post.py` in the website repository.
